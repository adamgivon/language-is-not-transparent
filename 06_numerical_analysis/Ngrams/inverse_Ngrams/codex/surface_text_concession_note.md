# Paper-Facing Concession Paragraph

Surface-text quantitative analyses were conducted using inverse n-grams, grouped and negative-space n-gram readings, `CONTROL` signature checks, 2-system sharing, KL-divergence, and stylometric measures. However, a matched replication test on three reruns of the same `CONTROL` configuration over the same 5-turn prompt sequence showed that within-system phrase-level variance is extremely high: exact trigram and quadgram overlap between reruns was very low and fell in roughly the same range as the between-system signal used in the original textual analysis. This means that, at one run per system per scenario, surface-text counts cannot cleanly separate architecture effects from ordinary stochastic variation in wording. For that reason, these analyses are not used here as main evidence for the paper’s core claim; they are treated instead as exploratory or methodological results, while the main argument rests on more robust analysis layers.
