# Conversations

This folder contains two versions of each conversation.

The first version appears in the root of each scenario folder. These files include the `ESSENCE` blocks where added, and do not include turn numbers.

The second version appears in the `textual_analysis/` folders. These files contain the same conversations, but with the `ESSENCE` blocks removed and turn numbers added. These were the versions used for collaborative close reading and textual analysis.

The `ESSENCE` blocks were removed from the textual-analysis versions because they were used for embedding and were not part of the assistant-user exchange being evaluated. Removing them also equalized the reading conditions, since some Control conversations did not include the blocks.
