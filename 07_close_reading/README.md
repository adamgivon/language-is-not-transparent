# Close-Reading Materials

This folder contains the qualitative close-reading materials used in the experiment.

Close reading was used to inspect how the different systems actually behaved in conversation: how they held tension, preserved or weakened user authority, handled affective speech, organized decisions, translated ideas into action, and followed the active constraints.

The full source conversations are not stored here. They are in:

`04_conversations/`

This folder contains the analytical layer built from those conversations.

## Recommended Reading Order

1. `codex_collaborative/`
   - The main close-reading evidence used for the paper.
   - Start here.

2. `opus_4.6_reads/`
   - Earlier supplementary reads covering only Scenario 5 and Scenario 7.
   - These are useful context, but not the main evidentiary basis.

## Main Folder: Codex Collaborative

`codex_collaborative/` contains the final collaborative close-reading work.

It includes:

- cross-scenario synthesis;
- scenario-level comparisons;
- per-system rereads;
- pattern ledgers;
- constraints comparisons;
- scoring notes;
- architecture mapping;
- methodology notes;
- raw human reading notes.

This is the primary folder for readers who want to inspect how the paper's qualitative findings were developed.

Start with:

`codex_collaborative/README.md`

## Supplementary Folder: Opus 4.6 Reads

`opus_4.6_reads/` contains an earlier non-collaborative close-reading pass.

These reads cover only:

- Scenario 5;
- Scenario 7.

The Opus 4.6 process was stopped because the reading quality and scoring were not strong enough to serve as the main basis for the paper. The folder is retained because it still contains useful observations and shows part of the methodological development.

Start with:

`opus_4.6_reads/README.md`

## Relationship To The Paper

The paper presents the conclusions and implications. This folder provides the support material behind the qualitative part of the experiment.

For the final evidence base, use `codex_collaborative/`.

For additional context and earlier model-led observations, use `opus_4.6_reads/`.
