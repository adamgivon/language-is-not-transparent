# Opus 4.6 Close-Reading Materials

This folder contains an earlier close-reading pass produced with Opus 4.6.

These materials cover only two scenarios:

- `scenario_5/`
- `scenario_7/`

They should not be read as equivalent to the Codex collaborative close-reading materials. The process here was different, and the reads were not collaborative. They were produced as model-led analytical reads with user guidance, but without the later iterative collaborative method of proposal, objection, rereading, correction, and revision.

## Status Of These Reads

The Opus 4.6 read was stopped before being extended to all scenarios.

The reason is methodological: the overall reading quality and scoring were not strong enough to serve as the main evidentiary basis for the paper. Some observations were useful, but the scoring and interpretive calibration were weaker than the later collaborative process.

For that reason, these files are included only as supplementary material.

## How To Use This Folder

Use these files for:

- additional observations;
- comparison with the later collaborative process;
- historical context for how the close-reading method developed;
- useful local insights that may not appear in the final synthesis.

Do not use these files as:

- the final scoring basis;
- the final comparative ranking;
- a replacement for the collaborative rereads;
- the primary evidence for the paper's claims.

The main close-reading evidence is in:

`07_close_reading/codex_collaborative/`

## Relationship To The Paper

The paper's qualitative conclusions rely on the collaborative close-reading process, not on this Opus 4.6 pass.

These materials are included because they still contain useful information and because they show part of the methodological development. They are best treated as a secondary support layer: informative, but not authoritative.
